Summary
-----------
This repository contains a detailed practical record of basic Linux commands executed on Ubuntu Linux using WSL. It covers essential topics such as navigating the Linux file system, creating and deleting files and directories, viewing and editing files, managing file permissions and ownership, and monitoring system resources. The commands are documented step by step to demonstrate hands-on practice and understanding of core Linux concepts, making this repository suitable for learning, revision, and academic submission purposes.
